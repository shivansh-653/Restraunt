# 🍽️ My Restaurant Website

A responsive, visually appealing restaurant landing page built using **HTML** and **CSS**. It showcases essential sections like Home, Services, About Clients, and Contact with smooth layout and responsive design for mobile screens.

## 🔧 Features

* ✅ Responsive design (mobile-friendly)
* ✅ Smooth navigation bar
* ✅ Attractive background sections using images
* ✅ Order Now call-to-action button
* ✅ Services showcase with icons and text
* ✅ About clients section with logos
* ✅ Working contact form layout

---

## 💡 Technologies Used

* HTML5
* CSS3 (Flexbox, Media Queries)
* Google Fonts (Baloo Bhai, Bree Serif)

---

## 🖥️ Sections Included

* **Navbar** – Logo + Navigation links
* **Home** – Welcome message with CTA
* **Services** – Three-card layout with images and description
* **Clients** – Logos displayed in a responsive row
* **Contact Us** – Form with Name, Email, Phone, and Message
* **Footer** – Copyright

---

## 📱 Responsive Design

* Optimized for screens **below 860px** via `phone.css`
* Navbar and service sections adjust for smaller viewports
* Images scale and stack properly on mobile
